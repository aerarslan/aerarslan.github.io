What is being calculated?

One response distance

d(f, g) = √[ (1 / M) ∑m=1…M ( f(xm) − g(xm) )² ]

These are fixed, noise-free ground truths. No GP is fitted and no observation noise is added. RMSE measures average difference and can hide local deviations.

Two spread controls

θi,j ∼ U(θbase,j + ρ(ℓj − θbase,j), θbase,j + ρ(uj − θbase,j))

Historical spread ρ shrinks the parameter ranges toward the base function. New-batch spread s moves g from its selected source toward a fixed random anchor. The selected source need not remain the closest after a large change.

Functions use the same formulas and ranges as the Python examples. This browser uses its own seeded random generator, so the same numeric seed does not reproduce PyTorch's exact samples.

Related benchmark families: Tighineanu et al., AISTATS 2022. The spread controls are our implementation extension.
