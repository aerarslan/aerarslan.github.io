Core workflow

The main notebook keeps the closed-loop optimization process explicit.

Choose settings → Create initial observations → Fit GP → Suggest next input → Run experiment → Add observation → Record BO step → Refit GP → Continue or stop
During the optimization itself, decisions are made from the observed data and the GP model belief. Hidden ground truth is used only for benchmark evaluation.

Experiment settings

The run is configured with ExperimentSettings(...), then created with VL(...).

ExperimentSettings(...)

ExperimentSettings(random_seed=..., strategy_label=..., dataset=..., number_of_initial_points=..., initial_design=..., surrogate_model=..., acquisition_function=...)

Defines the choices for one optimization run.

ArgumentMeaningChoices
random_seed Seed used for the stochastic parts of the run, including the initial design and observation noise. Integer
strategy_label Optional label written to the experiment record and reports. Text
dataset Selects the virtual experiment and therefore its dimension, bounds, and hidden objective. "2d_easy", "2d_hard", "5d", "power_plant"
number_of_initial_points Number of observations collected before fitting the first GP. Must be positive. Positive integer
initial_design Rule used to generate the initial input locations. VL.initial.sobol(), VL.initial.latin_hypercube(), VL.initial.random()
surrogate_model Surrogate-model choice used by fit_surrogate_model(). VL.models.single_task_gp()
acquisition_function Rule used by future calls to suggest_next_point(model). VL.acq.EI(), VL.acq.UCB(...), VL.acq.PI(), VL.acq.Mean(), VL.acq.Std(), or VL.acq.Custom(...) 
EXPERIMENT_SETTINGS = ExperimentSettings(
    random_seed=123,
    dataset="2d_easy",
    strategy_label="My BO run",
    number_of_initial_points=2,
    initial_design=VL.initial.random(),
    surrogate_model=VL.models.single_task_gp(),
    acquisition_function=VL.acq.EI(),
)

virtual_lab = VL(
    experiment_settings=EXPERIMENT_SETTINGS,
)

virtual_lab.print_experiment_plan()
To start a run with a custom acquisition function, pass the function to VL.acq.Custom(...) inside ExperimentSettings: 
acquisition_function=VL.acq.Custom(
    custom_acquisition_function,
    label="my acquisition",
)

The first argument is the Python function that selects a candidate. label is optional and is used in tracking and reports. Constants specific to the custom rule are defined inside the custom function rather than passed through VL.acq.Custom(...).

Each call to VL(...) creates a new timestamped experiment folder inside virtual_lab_runs/. The file global_observation_count.json keeps a cumulative count of stored observations across runs.

Datasets and available choices

SettingAvailable choices
Dataset2d_easy, 2d_hard, 5d, power_plant
Initial designVL.initial.random(), VL.initial.sobol(), VL.initial.latin_hypercube()
Surrogate modelVL.models.single_task_gp()
AcquisitionVL.acq.EI(), VL.acq.UCB(exploration_weight=...), VL.acq.PI(), VL.acq.Mean(), VL.acq.Std(), VL.acq.Custom(function, label=...)

2d_easy

A smooth two-dimensional synthetic optimization task. Model-belief plots are available.

2d_hard

A harder two-dimensional task with several broad competing high-value regions. Model-belief plots are available.

5d

A five-dimensional smooth synthetic optimization task. The BO workflow is unchanged, but 2D model-belief plots are not available.

power_plant

A four-input neural-network simulator for power-plant output. Its public bounds are in the original physical input units.

All four datasets use observation-noise standard deviation 0.03. The GP uses a BoTorch Normalize input transform and Standardize outcome transform internally. This is why the power-plant bounds can remain in physical units rather than being exposed as values between 0 and 1.

EI

VL.acq.EI()

Expected improvement. No arguments.

UCB

VL.acq.UCB(exploration_weight=2.0)

Combines posterior mean and posterior uncertainty.

exploration_weight: non-negative multiplier on posterior standard deviation. Default 2.0. Larger values give uncertainty more influence.

PI

VL.acq.PI()

Probability of improvement. No arguments.

Mean and Std

VL.acq.Mean() VL.acq.Std()

Mean() focuses on exploitation. Std() focuses on uncertainty. Neither takes arguments.

Custom

VL.acq.Custom(function, label="custom acquisition")

Wraps a Python candidate-selection function so it can be used as the active acquisition rule.

function: required callable used to select the candidate · label: optional readable name stored in tracking and reports.

Main functions used in the notebook

These are the main public calls used in the tutorial, in roughly the order they appear.

Create and inspect the run

VL(...)

virtual_lab = VL(experiment_settings=EXPERIMENT_SETTINGS)

Creates one virtual-lab run, initializes tracking, and creates its timestamped output folder. No observations are collected yet.

experiment_settings: required ExperimentSettings object · lab_config: optional advanced configuration, normally left at its default.

print_experiment_plan()

virtual_lab.print_experiment_plan()

Prints and records the selected dataset, initial design, surrogate model, acquisition rule, cost information, and output location.

No arguments.

Collect the initial observations

run_initial_design()

initial_design_points, initial_observed_y = virtual_lab.run_initial_design()

Generates the chosen initial design, evaluates it, stores the observations, and updates the observation counter and simulation cost.

No arguments. Uses the choices already stored in ExperimentSettings.

print_initial_design(...)

virtual_lab.print_initial_design(initial_design_points=initial_design_points, initial_observed_y=initial_observed_y)

Prints the initial points, observed responses, run observation count, and global observation count.

initial_design_points: tensor returned by run_initial_design() · initial_observed_y: corresponding noisy responses.

Fit and inspect the GP

fit_surrogate_model(...)

model = virtual_lab.fit_surrogate_model(record_fit=True)

Fits SingleTaskGP to all observations collected so far.

record_fit: when True, this fit is added to the model-fit history and its diagnostics are recorded. Default True.

plot_model_belief(...)

virtual_lab.plot_model_belief(model=model, show=True, save=False, save_path=None, filename=None)

For 2d_easy and 2d_hard, plots GP posterior mean and posterior standard deviation with the collected observations.

model: fitted GP to plot; if omitted, a temporary unrecorded GP is fitted when observations exist · show: display figure · save: save figure · save_path: explicit path overriding the normal run folder · filename: custom filename when saving to the normal model-belief folder.

Run one BO step

suggest_next_point(model)

candidate_x = virtual_lab.suggest_next_point(model)

Uses the current GP and active acquisition rule to propose the next experiment.

model: current fitted SingleTaskGP. The acquisition rule comes from the current experiment settings.

simulate_responses(points)

candidate_observed_y = virtual_lab.simulate_responses(candidate_x)

Runs the noisy virtual experiment and returns the observed response. It does not store the result or increase the stored observation count by itself.

points: one or more input locations inside the current search-space bounds.

add_observations(...)

virtual_lab.add_observations(candidate_x, candidate_observed_y, source=None)

Adds responses to the dataset. This is the storage step that increases the observation count and simulation cost.

points: input locations · observed_values: exactly one observed response per input · source: optional tracking label; when omitted, the virtual lab creates one from the acquisition rule.

record_bo_step(...)

virtual_lab.record_bo_step(candidate_x=candidate_x, candidate_observed_y=candidate_observed_y, bo_step_number=None)

Records the completed BO decision and the acquisition metadata associated with it.

candidate_x: selected candidate · candidate_observed_y: its stored response · bo_step_number: optional explicit step number; normally leave None and let the virtual lab increment it.

print_bo_step_summary(...)

virtual_lab.print_bo_step_summary(candidate_x=candidate_x, candidate_observed_y=candidate_observed_y)

Prints the latest candidate, observed response, best observed response so far, acquisition used, observation count, and simulation cost.

candidate_x: candidate from the completed step · candidate_observed_y: its observed response.

Plots and model history

The plotting functions serve different purposes. Model-belief and variance plots describe the fitted GP, while recommended utility and benchmark metrics use hidden ground truth for evaluation.

plot_model_belief(...)

virtual_lab.plot_model_belief(model=model, show=False, save=True, save_path=None, filename=None)

Plots or saves the current 2D GP posterior mean and standard deviation with observed points.

model: fitted GP; optional · show: display figure · save: save a PNG · save_path: explicit path · filename: custom filename in model_belief_plots/. Available only for 2d_easy and 2d_hard.

plot_average_variance_history(...)

virtual_lab.plot_average_variance_history(show=True, save=False, save_path=None, filename=None)

Plots the average GP posterior variance over the fixed reference set after each recorded model fit.

show: display figure · save: save figure · save_path: explicit path · filename: custom filename in the run's plots/ folder. Works for all datasets.

plot_recommended_utility_history(...)

virtual_lab.plot_recommended_utility_history(show=True, save=False, save_path=None, filename=None)

At each recorded fit, finds the reference point with the largest GP posterior mean and plots the hidden true utility at that recommended point.

show: display figure · save: save figure · save_path: explicit path · filename: custom filename. Works for all datasets, but uses hidden ground truth.

make_model_belief_gif(...)

virtual_lab.make_model_belief_gif(filename="model_belief_progression.gif", frame_duration_seconds=0.7)

Combines saved 2D model-belief frames into a GIF.

filename: GIF filename in the experiment folder · frame_duration_seconds: positive time shown per frame. Requires saved model-belief PNG frames and a 2D dataset.

virtual_lab.plot_recommended_utility_history(
    show=True,
    save=False,
)

virtual_lab.plot_average_variance_history(
    show=True,
    save=False,
)

if virtual_lab.supports_model_belief_plots:
    virtual_lab.make_model_belief_gif(
        frame_duration_seconds=1.0,
    )

Benchmark metrics

These diagnostics are useful in the virtual lab because hidden ground truth is available.

plot_benchmark_metrics(...)

virtual_lab.plot_benchmark_metrics(show=True, save=False, save_path=None, filename=None, log_scale=True)

Plots simple regret, inference regret, and function-learning RMSE against cumulative simulation cost.

show: display figure · save: save figure · save_path: explicit output path · filename: custom filename in the run's plots/ folder · log_scale: use a logarithmic y-axis when True.

QuantityWhat it evaluates
Simple regretHow good the best evaluated input is under the hidden true objective.
Inference regretHow good the GP's current posterior-mean recommendation is under the hidden true objective.
Function-learning RMSEHow accurately the GP posterior mean represents the hidden true function over the fixed reference set.
These quantities are benchmark-only. In a real experiment, the hidden true function and true optimum are usually unavailable, so stopping decisions must rely on observed data, model belief, cost, time, and scientific judgment.
In the tutorial workflow, the same current model is passed to finalize_experiment(model=model). Therefore the last point in the recommended-utility history corresponds to the hidden true utility of that final model recommendation.

Finalize and save the experiment

After deciding to stop, record the final model recommendation and save the complete run.

finalize_experiment(...)

final_model = virtual_lab.finalize_experiment(model=model)

Records the final model recommendation and benchmark summary, then returns the final GP.

model: optional current GP. Pass it to reuse the model already fitted on the final dataset. If omitted, a new GP is fitted and recorded.

print_final_summary()

virtual_lab.print_final_summary()

Prints final run counts, cumulative simulation cost, acquisition changes, and the experiment output folder.

No arguments.

save_all_outputs(...)

virtual_lab.save_all_outputs(final_model=final_model)

Saves the experiment metadata, tracking files, Markdown record, and available plots.

final_model: optional final GP. Supplying it enables final benchmark outputs and the final 2D model-belief plot. Without it, currently available tracking, metadata, notebook, and history outputs are still saved.

final_model = virtual_lab.finalize_experiment(
    model=model,
)

virtual_lab.print_final_summary()

virtual_lab.save_all_outputs(
    final_model=final_model,
)
The final model recommendation is the fixed reference point with the highest posterior mean under the final GP. The generated record keeps the recommendation location and posterior mean separate from hidden benchmark values used to evaluate it.

Optional helper tools

These functions and properties are not required by the main BO loop, but they are useful when extending the workflow.

suggest_alternative_points(...)

suggestions_x = virtual_lab.suggest_alternative_points(model, number_of_points=5, minimum_normalized_distance=0.08)

Returns several strong, separated candidates from the active acquisition rule without running the simulator or changing the dataset.

model: fitted GP · number_of_points: number of alternatives returned, default 5 · minimum_normalized_distance: minimum spacing between alternatives after normalizing the search space, default 0.08. Larger values enforce more separation.

set_acquisition(...)

virtual_lab.set_acquisition(VL.acq.UCB(exploration_weight=2.0))

Changes the acquisition rule used for future suggestions and records the change.

acquisition_function: an acquisition choice such as VL.acq.EI(), VL.acq.UCB(...), or VL.acq.Custom(...). Changing the acquisition does not refit the GP. Already pending suggestions keep the rule that created them.

get_observed_dataset()

observed_x, observed_y = virtual_lab.get_observed_dataset()

Returns all observed input locations and noisy responses currently stored in the run.

No arguments. Useful for fitting another model or inspecting the complete collected dataset.

take_note(...)

virtual_lab.take_note("My title", "My note", metrics=None)

Adds a manual note to the Markdown experiment record.

title: required non-empty title · text: optional note text, default empty · metrics: optional mapping of structured values saved with the note.

print_experiment_report()

virtual_lab.print_experiment_report()

Prints a compact report containing run history, final model recommendation, and benchmark information when available.

No arguments.

save_notebook(...)

virtual_lab.save_notebook(path=None)

Saves the current Markdown experiment record without running the full output-saving routine.

path: optional explicit output path. When omitted, saves to the normal virtual_lab_notebook.md path for the run.

clear_model_belief_plots()

removed_count = virtual_lab.clear_model_belief_plots()

Deletes saved 2D model-belief PNG frames from the run and returns how many were removed.

No arguments.

ucb_exploration_weight()

weight = virtual_lab.ucb_exploration_weight()

Returns the active UCB exploration weight. If the current acquisition does not store one, the method returns the default value 2.0.

No arguments.

Custom acquisition function

A custom acquisition function receives a candidate pool and information from the current GP, then returns one selected point. The implementation of the rule is left open.

Use it in ExperimentSettings

VL.acq.Custom(...) takes the custom Python function as its first argument and an optional readable label. The resulting acquisition choice is passed directly to ExperimentSettings. 

acquisition_function=VL.acq.Custom(
    custom_acquisition_function,
    label="my acquisition",
)
VL.acq.Custom(...) argumentMeaning
function Required callable containing the custom candidate-selection rule. For example, this can be the custom_acquisition_function template provided in the tutorial.
label Optional readable name used in the experiment plan, BO-step tracking, acquisition-change history, and saved reports. Default: "custom acquisition".
VL.acq.Custom(...) does not accept extra custom constants such as an exploration weight. Define constants needed by the rule inside the custom function itself.

Arguments passed to the custom function

When a custom acquisition is active, the virtual lab calls the function with these keyword arguments.

ArgumentMeaning
candidate_x Candidate locations available for selection. Shape is approximately (number_of_candidates, dimension).
model Current fitted SingleTaskGP. This allows more advanced rules to query the model directly if needed.
posterior_mean GP posterior mean evaluated at the supplied candidate locations.
posterior_standard_deviation GP posterior standard deviation at the candidate locations.
best_observed_y Best noisy response observed in the current dataset so far, provided as a Python float.
train_x All observed input locations used to fit the current GP. Shape (number_of_observations, dimension).
train_y All noisy observed responses used to fit the current GP. Shape (number_of_observations, 1).
bounds Lower and upper search-space limits. Shape (2, dimension). Power-plant bounds are in physical input units.
The function should return one selected input with shape (dimension,) or (1, dimension). In the normal tutorial workflow this should be a candidate selected from candidate_x. Hidden true objective values are not passed to the custom function.
The callback does not receive posterior_variance as a separate public argument. If variance is needed, it can be obtained by squaring posterior_standard_deviation.

Change the acquisition during an existing run

The acquisition rule can also be changed during an existing run with set_acquisition(...). For example: 

virtual_lab.set_acquisition(
    VL.acq.EI()
)

This changes future acquisition suggestions but does not refit the GP. A candidate that was already suggested keeps the acquisition rule that originally selected it.

save_all_outputs(final_model=final_model) automatically saves the average-variance and recommended-utility history plots when model fits exist. Supplying final_model also saves the benchmark plot and, for a 2D run, the final GP-belief plot.
The generated virtual_lab_notebook.md contains the run notes, current status, acquisition changes, BO-step history, surrogate-model fit history, and observed dataset. The fit-history table includes average posterior variance and recommended true utility.
Plotting, GP fitting, and benchmark calculations do not increase the global observation count. Initial-design observations and observations stored with add_observations(...) do.

Useful distinctions

ComparisonDifference
simulate_responses(...) vs. add_observations(...) The first returns a noisy response without storing it. The second stores the response and increases the observation count and simulation cost.
Best observed response vs. final model recommendation The best observed response is the largest noisy measurement seen so far. The final recommendation is the reference point where the final GP posterior mean is largest.
plot_average_variance_history() vs. plot_recommended_utility_history() Average variance summarizes GP uncertainty. Recommended utility evaluates each GP recommendation using hidden ground truth.
plot_model_belief(...) vs. plot_benchmark_metrics(...) Model belief visualizes the GP and is only available for 2D datasets. Benchmark metrics use hidden ground truth and work for every dataset.
fit_surrogate_model() vs. finalize_experiment(model=model) The first fits and records a GP state. The second reuses the supplied final GP and records the final recommendation and benchmark summary.
VL.acq.Mean() vs. VL.acq.Std() Mean is exploitation-oriented. Std is uncertainty-oriented.
